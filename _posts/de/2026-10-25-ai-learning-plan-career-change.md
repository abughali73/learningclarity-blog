Ein Berufswechsel ist spannend, doch die erste Frage ist oft die schwierigste: Wo fange ich überhaupt an? Ein **KI-Lernplan** gibt die Antwort. Sie beschreiben Ihr großes Ziel, zum Beispiel „Vorbereitung auf eine Laufbahn in der Datenanalyse“, und LearningClarity macht daraus einen vollständigen Lehrplan aus Kursen, dem Sie Schritt für Schritt folgen.

## Was Ihnen ein KI-Lernplan bietet

{% include scene.html n=1 %}

Ein **AI Learning Plan (KI-Lernplan)** in LearningClarity ist ein kompletter Lehrplan aus mehreren Kursen, die alle auf ein gemeinsames, größeres Ziel ausgerichtet sind. LearningClarity erstellt den Plan und seine Kurse für Sie und kann die beste Reihenfolge vorschlagen, in der Sie sie bearbeiten.

Alles folgt einer klaren Struktur: **Lernplan > Kurs > Thema > Unterthema**. Der Plan zeigt das große Ganze, jeder Kurs deckt einen Bereich ab, jedes Thema konzentriert sich auf ein Fachgebiet, und die Unterthemen sind die kleinen Einheiten, die Sie tatsächlich lernen. Wenn Sie bereits mit dem [KI-Kursgenerator einen Kurs erstellt haben](/de/2026/10/ai-course-generator-guide/), ist der Plan die nächste Stufe: mehrere Kurse, die zusammenspielen.

## Berufswechsel Schritt für Schritt

{% include scene.html n=2 %}

Angenommen, Sie arbeiten im Einzelhandel und möchten in die Datenanalyse wechseln. So macht ein Lernplan den Umstieg überschaubar:

1. **Ziel beschreiben.** Formulieren Sie es in einfachen Worten, so wie Sie es einer Mentorin oder einem Mentor erklären würden.
2. **Lehrplan ansehen.** LearningClarity erstellt die Kurse, aus denen der Plan besteht, jeweils mit eigenen Themen und Unterthemen.
3. **Der vorgeschlagenen Reihenfolge folgen.** Beginnen Sie mit dem Kurs, den LearningClarity zuerst vorschlägt, damit die Grundlagen vor dem anspruchsvolleren Stoff kommen.
4. **Schwerpunkte setzen.** In jedem Thema wählen Sie selbst, auf welche Unterthemen Sie sich konzentrieren; der Abschluss wird für jedes einzeln erfasst.

Ihr Plan kann auch in der Sprache sein, in der Sie lernen möchten. Neue Pläne verwenden standardmäßig die App-Sprache, und Sie können die Lernsprache vor dem Erstellen ändern.

## Lernen, üben und nachweisen

{% include scene.html n=3 %}

Jedes Thema im Plan funktioniert wie jedes andere Thema in LearningClarity. **Explain Mode (Erklärmodus)** vermittelt Ihnen jeweils einen kurzen Abschnitt, **Quiz Mode (Quizmodus)** bietet Übung ohne Druck, und **Exam Mode (Prüfungsmodus)** kann ein einzelnes Thema oder einen ganzen Kurs prüfen. Qualifizierende Prüfungsergebnisse bringen ein Zertifikat für das Thema oder den Kurs – ein wertvoller Meilenstein auf dem Weg in den neuen Beruf.

{% include scene.html n=4 %}

Ihr Fortschritt wird auf jeder Ebene erfasst, von den Unterthemen über die Kurse bis zum Plan selbst. So sehen Sie auch in einer vollen Woche mit einem Blick in die App, wie weit Sie gekommen sind.

## Auch für Teams und Familien

{% include scene.html n=5 %}

Die Idee funktioniert auch über den eigenen Berufswechsel hinaus. Weiterbildungsverantwortliche können einen Plan einmal erstellen und per E-Mail mit Kolleginnen und Kollegen teilen, die LearningClarity nutzen; wer annimmt, erhält eine unabhängige Kopie und verfolgt den eigenen Fortschritt. Eltern oder Mentoren, die einen Lernenden begleiten, erhalten E-Mail-Berichte, die auch den Fortschritt in Lernplänen enthalten.
