Manchmal sind die Augen schneller müde als der Kopf. Nach einem langen Arbeitstag, einem Vormittag voller Vorlesungen oder einem Abend mit Hausaufgaben wirkt jede weitere Seite Text wie ein Berg. Genau dann hilft Lernen durch Zuhören, denn der KI-Tutor von LearningClarity kann Ihnen die Lektion vorlesen.

{% include scene.html n=1 %}

Die Funktion heißt **Listen (Vorlesen)**. Sie ist Teil des **Explain Mode (Erklärmodus)**, des interaktiven Tutors, der Ihnen ein Unterthema in kurzen Abschnitten erklärt. Tippen Sie auf Listen, und die aktuelle Erklärung wird laut vorgelesen. Wenn Sie bereit sind, wählen Sie Next (Weiter) und gehen in Ihrem eigenen Tempo voran.

## So funktioniert Lernen durch Zuhören im Explain Mode

{% include scene.html n=2 %}

Der Ablauf ist einfach:

1. Öffnen Sie ein Thema und wählen Sie das Unterthema, das Sie lernen möchten.
2. Starten Sie den Explain Mode und warten Sie auf den ersten Abschnitt.
3. Tippen Sie auf **Listen**, um ihn zu hören, und wählen Sie dann **Next** für den nächsten Abschnitt.

Ist ein Abschnitt zu schwierig, formuliert **Simplify (Vereinfachen)** ihn einfacher. Ist er zu leicht, ergänzt **Explain Further (Mehr erklären)** Details und Beispiele. Sie können auch eine eigene Frage zum Abschnitt stellen oder um ein Beispiel bitten. Und weil die Erklärungen an das Alter der lernenden Person angepasst werden, hören Jugendliche und Erwachsene jeweils eine Erklärung auf ihrem Niveau.

## 3 Momente, in denen auditives Lernen mit KI hilft

{% include scene.html n=3 %}

**Wenn die Augen eine Pause brauchen.** Lehnen Sie sich zurück, schließen Sie die Augen und lassen Sie die Erklärung zu sich kommen. Viele Lernende merken, dass ein Gedanke anders hängen bleibt, wenn sie ihn hören statt lesen.

**Wenn Sie von Hand mitschreiben möchten.** Hören Sie zu, während Sie auf Papier schreiben. So bleibt Ihre Aufmerksamkeit beim Inhalt, statt ständig zwischen Bildschirm und Heft zu springen. Das passt besonders gut zu auditiven Lerntypen.

**Wenn Sie gemeinsam lernen.** Eltern können mit ihrem Kind einen Abschnitt anhören und darüber sprechen, bevor es weitergeht. Eine Trainerin oder ein Trainer kann einer kleinen Gruppe einen Abschnitt vorspielen, als Einstieg in die Diskussion.

{% include scene.html n=4 %}

Wenn Sie mittendrin aufhören, bringt **Resume (Fortsetzen)** Sie genau dorthin zurück, wo Sie stehen geblieben sind. So ist keine kurze Hörsession verschenkt.

## Erst zuhören, dann prüfen, was hängen geblieben ist

{% include scene.html n=5 %}

Eine Erklärung zu hören heißt noch nicht, sie zu behalten. Deshalb bietet der Explain Mode **Knowledge Checks (Wissenschecks)**: Multiple-Choice-Fragen während der Erklärung, mit Feedback zu Ihrer Antwort. Liegen Sie daneben, können Sie es mit **Retry (Erneut versuchen)** noch einmal probieren. Und wenn Sie mehr üben möchten, wählen Sie im Quiz Mode (Quizmodus) Unterthemen und Fragetypen aus, mit einer Option „Ich weiß es nicht“, die ein ehrlicheres Bild liefert als Raten.
