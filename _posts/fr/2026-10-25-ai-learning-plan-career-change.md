Se reconvertir est motivant, mais la première question est souvent la plus difficile : par où commencer ? Un **plan d'apprentissage IA** y répond. Vous décrivez votre grand objectif, par exemple « Me préparer à une carrière dans l'analyse de données », et LearningClarity le transforme en programme complet de cours à suivre étape par étape.

## Ce qu'un plan d'apprentissage IA vous apporte

{% include scene.html n=1 %}

Un **AI Learning Plan (plan d'apprentissage IA)** dans LearningClarity est un programme complet composé de plusieurs cours, tous tournés vers un même objectif plus large. LearningClarity génère le plan et ses cours pour vous, et peut vous suggérer le meilleur ordre pour les étudier.

Tout s'organise selon une structure claire : **plan d'apprentissage > cours > sujet > sous-sujet**. Le plan donne la vue d'ensemble, chaque cours couvre un domaine, chaque sujet se concentre sur une matière, et les sous-sujets sont les petites unités que vous étudiez réellement. Si vous avez déjà utilisé le [générateur de cours IA pour créer un cours](/fr/2026/10/ai-course-generator-guide/), le plan est l'étape suivante : plusieurs cours qui fonctionnent ensemble.

## Une reconversion, étape par étape

{% include scene.html n=2 %}

Imaginons que vous travailliez dans le commerce et souhaitiez évoluer vers l'analyse de données. Voici comment un plan rend cette transition plus maîtrisable :

1. **Décrivez votre objectif.** Formulez-le simplement, comme vous l'expliqueriez à un mentor.
2. **Parcourez le programme.** LearningClarity génère les cours qui composent le plan, chacun avec ses sujets et sous-sujets.
3. **Suivez l'ordre suggéré.** Commencez par le cours que LearningClarity propose en premier, pour aborder les bases avant les notions plus difficiles.
4. **Concentrez-vous sur l'essentiel.** Dans chaque sujet, vous choisissez les sous-sujets sur lesquels vous concentrer, et leur achèvement est suivi un par un.

Votre plan peut aussi être dans la langue de votre choix. Les nouveaux plans utilisent par défaut la langue de l'application, et vous pouvez changer la langue d'apprentissage avant de les créer.

## Apprendre, s'entraîner et le prouver

{% include scene.html n=3 %}

Chaque sujet du plan fonctionne comme n'importe quel autre sujet dans LearningClarity. **Explain Mode (mode explication)** vous enseigne une courte section à la fois, **Quiz Mode (mode quiz)** vous permet de vous entraîner sans pression, et **Exam Mode (mode examen)** peut évaluer un seul sujet ou un cours entier. Les résultats d'examen qualifiants donnent droit à un certificat pour le sujet ou le cours : un jalon utile dans une reconversion.

{% include scene.html n=4 %}

Vos progrès sont suivis à chaque niveau, des sous-sujets jusqu'aux cours et au plan lui-même. Même lors d'une semaine chargée, vous ouvrez l'application et voyez exactement où vous en êtes.

## Pour les équipes et les familles aussi

{% include scene.html n=5 %}

L'idée va au-delà d'une reconversion personnelle. Un responsable formation peut créer un plan une seule fois et le partager par e-mail avec des collègues qui utilisent LearningClarity ; chaque personne qui accepte reçoit une copie indépendante et suit ses propres progrès. Un parent ou un mentor qui accompagne un apprenant reçoit des rapports par e-mail qui incluent la progression dans les plans.
